# sankethskamath.github.io

Sanketh Kamath's personal site: a home page with an interactive WebGL blob, plus
resume, projects, blog, notes and contact pages. Plain HTML, CSS and JavaScript,
with no framework. GitHub Pages serves this folder as it is.

## Changing the site

Edit the files in `content/`, then rebuild:

    pip install markdown pymdown-extensions
    python3 build.py

| To change | Edit |
| --- | --- |
| Name, tagline, email, links, projects, resume | `content/site.json` |
| The resume PDF | replace `assets/sanketh-kamath-resume.pdf` (the build remakes its page pictures if `pdftoppm` is installed) |
| Blog posts | `content/posts/YYYY-MM-DD-short-name.md` |
| Notes | `content/notes/YYYY-MM-DD-short-name.md` |
| Images and plots for posts and notes | `assets/img/` |
| Look and layout | `assets/css/site.css` |
| The blob | `assets/js/blob.js` |

A post or note starts with a short header:

    ---
    title: The title
    summary: One line shown in the blog list
    ---

    The text, in Markdown.

Posts and notes can use LaTeX (`$inline$` and `$$display$$`), code blocks, tables
and images. An image on its own line becomes a figure, and its title is the caption:

    ![What it shows](../assets/img/file.png "Optional caption")

Text wrapped in `[[double brackets]]` in `site.json` shows with a dotted underline,
to mark it as a placeholder. Remove the brackets once the text is real.

The `*.html` files, `posts/` and `notes/` are generated by `build.py`. Change the
content or the script, not those files.
